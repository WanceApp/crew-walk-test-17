# Market brief: AI code-review tools for small teams

## Summary

AI code-review tools comment on pull requests automatically, catching bugs, style issues and missing tests before a human reads the diff. Small teams (roughly 2-20 engineers) buy them to offset a shortage of reviewers, and mostly pay per seat on a monthly plan. The category is crowded and moving fast, and this brief could not verify any market-size figure.

## Market size

- No sourced figure was obtained. This brief was written without live web access, so no number is cited.
- Estimate (unverified): the category is a small, fast-growing slice of the wider AI developer-tools market. Do not quote a dollar value from this document.

## Key players

Listed from general knowledge, not re-checked for this brief (pricing and features not verified):

- **GitHub Copilot code review** - bundled in the GitHub platform most small teams already use.
- **CodeRabbit** - dedicated PR-review bot, supports GitHub and GitLab.
- **Qodo (formerly CodiumAI)** - review plus test generation.
- **Greptile** - reviews using whole-codebase context.
- **Graphite** - stacked-PR workflow with built-in AI review.

## Trends

- Bundling: platform vendors fold review into existing seats, pressuring standalone tools on price.
- Context: tools compete on understanding the full repository, not just the diff.
- Scope creep: review tools add test generation, auto-fix suggestions and merge workflows.

## Risks and unknowns

- Market size, growth rate and pricing are unverified.
- Accuracy is unmeasured here: false positives and review noise are the main reasons teams drop these tools.
- Code privacy and data-retention terms of each vendor were not reviewed.
- The player list is from memory and may be out of date (acquisitions, renames, shutdowns).
